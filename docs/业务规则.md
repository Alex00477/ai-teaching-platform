# 业务规则

## 文档职责

本文档是 P0 业务规则的唯一事实来源：开发、接口设计和验收遇到冲突时以此为准。它只记录角色权限、核心状态、关键规则和必须处理的异常，不替代技术方案或详细测试设计。

## 角色与权限

| 角色 | 允许操作 | 明确禁止 |
| --- | --- | --- |
| 学生 | 管理自己的资料；查看所属班级的已发布作业和讲义；保存草稿、提交自己的作业；查看自己的已确认批改；请求自己的错题讲解 | 加入第二个班级；读取其他学生/班级数据；修改已提交作业或教师批改；查看未发布讲义；调用教师管理操作 |
| 教师 | 管理自己负责的多个班级；创建/发布作业；查看和批改本班提交；发起整份 AI 批改并确认；上传/发布本班讲义 | 读取或修改其他教师的班级、提交、讲义；用修改资源 ID 的方式越权 |
| 系统 | 从服务端会话判断身份和资源归属；保存状态；创建异步任务；调用 PH8；记录结果和失败原因 | 把 API Key 给浏览器；让模型决定权限、归属或发布状态；绕过服务端授权 |

## 核心规则

1. 账号只有学生或教师一种身份；登录页选择的角色不能作为授权来源。注册需使用按身份区分的邀请码，邀请码只负责准入，不绑定班级。
2. 学生最多有一个有效班级关系；教师可以负责多个班级。学生注册后用教师生成的班级码加入，加入检查和写入必须在同一事务中完成。
3. 教师只能操作自己负责的班级及其作业、提交、批改和讲义；所有读取和写入都在服务端按当前会话做资源归属检查。
4. 作业属于一个班级和科目，只支持选择题、填空题、简答题。简答题必须有正整数满分和评分要点。
5. 草稿不等于提交；提交时保存不可变答案快照。提交成功后学生不能直接修改或重复创建有效提交。
6. AI 批改以整份作业为一个异步任务。同一提交只能有一个运行中任务；结果必须先进入“待教师确认”，确认后才是学生可见的正式批改。
7. 错题讲解只读取该学生已经可见的题目、答案和批改反馈，不需要教师审核，但失败不改变正式批改结果。
8. 讲义上传后默认为“未发布”，只有教师明确发布且班级/科目匹配时学生可见。列表、详情和下载都要再次鉴权。
9. API Key 只保存在服务端环境变量或密钥管理器中；设置页只显示“已配置”或掩码结果。日志、前端、Git、普通数据库字段和模型上下文不得出现明文 Key。
10. Agent 只能调用受控查询或业务动作；涉及批改、写入等副作用时需明确确认，不能执行任意 SQL、路径、系统命令、Skill 安装或 MCP 工具。

## 核心状态

```text
作业：草稿 → 已发布
提交：草稿 → 已提交 → 批改中 → 待教师确认 → 已批改
                         └──────────────→ 失败
讲义：未发布 → 已发布
AI 任务：等待处理 → 处理中 → 待教师确认 → 已确认
                              └──────────────→ 失败
```

- 人工批改可以从“已提交”进入编辑并确认；AI 失败不删除提交，也不阻塞人工批改。
- 任务和批改结果必须绑定提交快照/作业版本，旧任务不能覆盖新版本或人工结果。
- 讲义知识库索引属于发布后的附加处理，索引失败不能改变可见性。

## 必须处理的异常

| 场景 | 处理要求 |
| --- | --- |
| 邀请码/班级码无效、过期、次数用尽或身份不匹配 | 拒绝操作，不创建半成品关系；不泄露可用于兑换的明文凭证 |
| 学生重复加入班级或并发加入 | 服务端唯一性约束/事务保证最多一个有效班级，保留原关系 |
| 重复提交、截止后提交、提交时失去权限 | 以服务端状态为准；不创建重复快照，失败不误标记为已提交 |
| 直接修改角色、班级、作业、讲义 ID | 服务端按会话和资源归属拒绝，不返回目标数据 |
| PH8 超时、限流、网络错误、空响应或格式不符 | 任务失败并保留原因；不发布学生可见结果，人工批改仍可用 |
| 重复点击 AI 批改或页面关闭 | 返回已有运行中任务；任务在服务端继续，重新进入可查询 |
| 任务完成时版本变化或已有人工结果 | 拒绝静默覆盖，提示冲突或要求重新处理 |
| 未发布讲义被列表、详情或直链访问 | 所有路径拒绝；文件存储不作为权限凭证 |
| 恢复码错误、过期或重复使用 | 密码不变，不透露正确凭证；成功重置后旧会话失效 |

## 安全与一致性底线

- 接口按“认证 → 角色 → 资源归属 → 当前状态 → 执行”顺序处理；前端隐藏按钮不算授权。
- 查询条件直接带上当前用户和资源归属，列表分页并限制返回量；缓存命中不能绕过鉴权。
- 注册、提交、发布讲义和创建 AI 任务必须具备幂等或唯一约束；敏感操作做基本限流和审计。
- 错误对用户可理解但不返回堆栈、路径、密钥、完整上游响应或其他用户数据。
