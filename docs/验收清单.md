# 验收清单

## 使用约定

本清单只保留 P0 主流程和最高风险场景，业务规则以 [业务规则](业务规则.md) 为准。表中的“拒绝”必须在服务端直接调用接口时同样成立；异步场景必须验证刷新或关闭页面后重新进入。

## 账户与班级

| 编号 | 前置与操作 | 预期结果 |
| --- | --- | --- |
| AUTH-01 | 用有效的学生/教师邀请码注册并登录 | 创建对应角色账号，进入正确首页；错误、过期、次数用尽或角色不匹配的邀请码被拒绝 |
| AUTH-02 | 使用错误密码或错误角色登录 | 返回统一失败提示，不泄露账号是否存在，不创建错误会话；连续失败受到限流 |
| AUTH-03 | 用一次性恢复码设置新密码，再次使用旧码 | 新密码可登录，旧会话失效；旧码不能再次使用且不泄露正确凭证 |
| CLASS-01 | 教师创建两个班级、生成班级码，学生用有效班级码加入 | 教师只看到自己的班级；学生只能看到所属班级；班级码明文只在生成响应中返回 |
| CLASS-02 | 已有班级的学生并发或重复加入其他班级；教师重新生成或撤销班级码 | 服务端拒绝重复加入，最多保留一条有效班级关系；旧码失效 |
| AUTHZ-01 | 学生/无关教师直接改角色、班级、作业或讲义 ID 读取/写入 | 服务端拒绝，不返回目标数据、不改变原数据 |

## 作业与提交

| 编号 | 前置与操作 | 预期结果 |
| --- | --- | --- |
| HW-01 | 教师创建含三类题型的作业并发布 | 草稿阶段学生不可见；发布后仅目标班级学生可见 |
| HW-02 | 学生保存部分答案、刷新后提交整份作业 | 草稿可恢复；提交保存不可变答案快照，教师可见“已提交” |
| HW-03 | 学生连续点击提交、刷新后再次提交或截止后提交 | 不产生重复有效提交；截止后由服务端拒绝，原草稿/提交状态不被误改 |
| HW-04 | 学生提交时退出班级或作业权限被撤销 | 服务端拒绝，不生成有效提交 |

## 批改与 AI 任务

| 编号 | 前置与操作 | 预期结果 |
| --- | --- | --- |
| GRADE-01 | 所属教师人工批改并确认提交 | 结果与提交版本关联；学生只看到已确认反馈 |
| AI-01 | 教师对已提交作业点击 AI 批改 | 立即返回任务 ID/状态，不等待模型；同一提交再次点击返回已有任务 |
| AI-02 | 创建任务后关闭页面，模拟 PH8 成功，再重新进入 | 任务继续执行；结果进入待教师确认，确认后才对学生可见 |
| AI-03 | 模拟 PH8 超时、限流、网络错误或格式错误 | 任务失败并保留原因；提交和人工批改入口仍可用 |
| AI-04 | AI 运行期间产生人工结果或提交版本变化 | 旧 AI 结果不能静默覆盖，系统提示冲突/要求重新处理 |
| EXPLAIN-01 | 学生对自己的已确认错题请求讲解；再请求他人/未确认错题 | 前者返回讲解或可重试失败；后者服务端拒绝，不泄露上下文 |

## 讲义与 Agent

| 编号 | 前置与操作 | 预期结果 |
| --- | --- | --- |
| NOTE-01 | 教师上传 PDF/DOCX，先不发布，再发布 | 未发布仅教师可见；发布后仅匹配班级/科目的学生可见 |
| NOTE-02 | 学生通过列表、猜测 ID 或直链访问未发布讲义 | 所有路径均拒绝，不能读取元数据或文件 |
| AGENT-01 | 学生查询自己的作业，教师查询自己班级统计 | Agent 只使用当前会话有权访问的数据 |
| AGENT-02 | 用户要求跨班级读取或直接执行写入/工具 | 拒绝越权；有副作用的动作必须先确认并走受控业务流程 |

## P0 通过条件

- 上述主流程和关键失败/越权场景均可执行并通过。
- AI 批改始终是整份作业异步任务，教师确认前不成为正式学生反馈。
- 讲义发布状态、服务端授权、重复提交和任务失败的行为与 [业务规则](业务规则.md) 一致。
