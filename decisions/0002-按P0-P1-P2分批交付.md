# ADR-0002：按 P0、P1、P2 分批交付

- 状态：已确认
- 日期：2026-09-13
- 影响范围：产品范围、开发计划、验收和发布

## 背景

平台需求同时包含学生端、教师端、作业、讲义、Agent、知识库、Skill、MCP、性能和安全要求。若一次性实现所有能力，最小教学闭环会被通用 Agent 能力和基础设施工作分散，难以判断第一版是否真正可用。

## 决策

采用三批交付：

- P0：完成“班级—作业—批改—反馈”最小闭环，包括学生/教师账号、班级、三类题型、作业提交、人工批改、整份异步 AI 批改、错题讲解和已发布讲义查看；
- P1：补齐知识库检索、受控 Agent 查询、缓存、搜索、任务重试和压测；
- P2：延期通用 Skill 市场、任意 MCP、管理员后台、复杂题型、移动端和多租户运营能力。

## 影响

- P0 的功能和验收可以独立进行，不以通用插件系统为前置条件；
- P0 仍必须保留权限、密钥保护和异步任务边界，避免以后返工；
- Agent 在 P0 只提供受控入口，不承诺任意自然语言执行；
- P1/P2 的延期内容必须在计划和界面中明确标注，不能被误认为已支持。

## 验证方式

P0 必须通过 [docs/验收清单.md](../docs/验收清单.md) 中的核心验收项，并满足 [docs/技术方案.md](../docs/技术方案.md) 规定的异步、权限和故障隔离约束。
