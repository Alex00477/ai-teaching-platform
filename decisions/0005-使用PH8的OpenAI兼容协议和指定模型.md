# ADR-0005：使用 PH8 的 OpenAI 兼容协议和指定模型

- 状态：已确认
- 日期：2026-09-13
- 影响范围：模型客户端、AI 批改、错题讲解、Agent

## 背景

平台需要接入大模型完成整份作业批改和错题讲解，同时希望避免在业务代码中绑定某个厂商的专用 SDK。PH8 中转站提供 OpenAI 兼容协议，可以使用统一的请求结构接入。

## 决策

- 模型服务通过 PH8 中转站的 OpenAI 兼容 API 调用；
- API地址为https://ph8.co/v1/chat/completions
- 首批模型使用 `deepseek-v4-flash`；
- API Key 只通过服务端环境变量或专用密钥管理器提供；
- 浏览器只能调用本平台后端，不能直接携带 PH8 Key；
- 模型输出必须经过格式、题目数量、状态和权限校验；
- PH8 的 API 基地址、超时、重试、限流和错误映射在技术设计阶段配置。

## 影响

- 需要抽象模型客户端，避免 PH8 细节散落在业务逻辑中；
- 需要为模型不可用、限流、认证失败、响应格式错误准备可观察的失败路径；
- 需要在部署环境单独配置新生成的生产 Key，不能把 Key 写入仓库；
- 未来切换其他 OpenAI 兼容服务时，业务层可以复用主要接口，但模型行为和容量仍需重新验证。

## 安全说明

此前有 API Key 在对话中暴露，实际接入前必须在 PH8 控制台撤销旧 Key 并生成新 Key。新 Key 不写入本文档、不提交 Git，也不在日志中输出。
